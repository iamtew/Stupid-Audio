About Stupid Audio

Stupid Audio is a collection of free, open-source VST3 plugins/standalone instruments. Built by the author because these tools were missing from the session, then shared in case someone else finds them useful too. Open source under MIT, because free is good!

Acid lines. Kicks. Percussion. Pads and atmosphere. Psytrance fart noises. Every plugin has a job. The goal is simple: load it, make the sound, get on with the track. Each plugin lives in its own GitHub repository with its own website, manual, downloads, and release schedule. A kick synth shouldn't have to wait for a pad synth update, and vice versa.

This site is just the catalog. Find the tool you need, click through, download it, make noises. If it helped you finish a track, it worked.
